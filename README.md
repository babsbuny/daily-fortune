# Daily Fortune 🔮

카드를 뒤집어 오늘의 운세와 행운의 아이템을 확인하는 Next.js 웹앱입니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 열면 됩니다.

## 기능

- 버튼 클릭 시 3D 카드 플립 애니메이션
- 랜덤 운세: 영문 키워드 + 한글 부제 + 행운 지수(LUCK) + 메시지
- 랜덤 행운의 아이템
- 블랙 & 골드 타로 카드 디자인 (Cormorant Garamond + Pretendard)

## 기술 스택

- Next.js 15 (App Router)
- React 19
- 순수 CSS (외부 UI 라이브러리 없음)
